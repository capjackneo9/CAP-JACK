# Voice commands (broadcast console)

Chrome or Edge on a computer. Studio → **Broadcast console** → **Turn on voice commands** (allow the microphone).

Start every command with **“console”** so your normal on-air talk never triggers anything
(you can switch the wake word off, but it's not recommended while presenting).

| Say | Does |
|---|---|
| console, play deck A / pause deck B | Start or pause a deck |
| console, cue deck A | Back to the start of the track |
| console, load next / load next on deck B | Next queued track to a free deck / that deck |
| console, deck A louder / deck B quieter | Channel volume up or down |
| console, crossfade to deck B / center the crossfader | Move the crossfader |
| console, mic on / mic off / mute mic / unmute mic | Microphone |
| console, play pad 3 | Fire a pad (1–8) |
| console, start recording / stop recording | Record the program |
| console, go live → **confirm** | Start broadcasting |
| console, end broadcast → **confirm** | Hand back to AutoDJ |
| cancel | Forget a command waiting for “confirm” |
| console, help | Show the list |

- **Go live** needs your DJ username and password already typed in the transmitter, and waits 10 seconds for “confirm”.
- If your mic is ON, listeners hear the command too — say commands with the mic closed or muted.
- **Is it hearing me?** While listening, the panel shows *Listening on: <mic name>*, a level bar that moves when you talk,
  “Speech engine connected” and “Hearing speech”. Voice commands use Chrome’s **default** microphone: change it from the
  padlock / mic icon in the address bar, or Windows → Settings → Sound → Input, then turn voice commands off and on.
  Chrome turns speech into text using Google's speech service, so it needs an internet connection.
